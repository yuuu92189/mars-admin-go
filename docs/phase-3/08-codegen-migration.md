# Codegen Migration

## Implemented

- Three-step pipeline visual.
- PostgreSQL table listing.
- Import selected tables through `POST /api/v1/admin/codegen/imported`.
- Imported table list, search, and pagination.
- Metadata editor for class/package/module/business/function/author/path/front-end fields.
- Field mapping table from real imported columns.
- Preview through the imported-table preview endpoint.
- Structure sync.
- ZIP download through `GET /api/v1/admin/codegen/download?ids=...`.
- Imported configuration deletion without deleting the database table.

## Contract Corrections

- Raw database tables and imported codegen tables now have separate schemas.
- Imported columns include nullable, default, comment, and primary-key metadata.
- Preview uses `CodegenOutput` with file paths and warnings.

## Security

- No browser-side template execution.
- No arbitrary filesystem path execution.
- Generated bytes come from the Go service.
