# Type Mapping

| Legacy MySQL | New PostgreSQL / Go |
|---|---|
| `BIGINT AUTO_INCREMENT` | `UUID` generated by Go UUIDv7; old ID held in reviewed mapping manifest |
| `VARCHAR/TEXT` | `VARCHAR` for bounded values, `TEXT` for documents; Go string |
| `TINYINT(1)` status | explicit text enum + `CHECK`; Go string |
| `TINYINT` gender/type | `SMALLINT`/`VARCHAR`; Go `int16`/string |
| `DATETIME` | `TIMESTAMPTZ`; Go `time.Time` in UTC |
| `DATE` | `DATE` |
| JSON-in-TEXT | `JSONB`; Go DTO/map or typed document |
| `DECIMAL` | `NUMERIC`; Go decimal-safe representation when monetary |
| `BLOB` | `BYTEA` |
| `INT` sorting/counters | `INTEGER`/`BIGINT`; Go `int32`/`int64` |

## Time Conversion Rule

The source `DATETIME` has no timezone. Imports must receive an explicit reviewed source timezone and reject ambiguous DST values. Runtime code persists all times as UTC.

## Identifier Rule

Never send legacy `BIGINT` to JavaScript as a number. Import maps old IDs to UUIDs and stores the relationship manifest under restricted migration control.
